# 时空酒馆 · The Crossroads Tavern

> 一座漂浮在万界十字路口的 3D 网页酒馆 —— WorkBuddy「1024 程序员节」应用创作大赛参赛作品。

[![体验地址](https://img.shields.io/badge/体验-GitHub%20Pages-blue)](https://cosmowind.github.io/crossroads-tavern/)

---

## 这是什么

《时空酒馆》是一座用原生 **Three.js** 打造的第一人称 3D 网页酒馆。玩家推门而入，会发现自己站在时空的十字路口：中庭通向四座风格迥异的厅堂——中土炉火、赛博霓虹、修仙竹影、秘法星辰。每一座厅都藏着一枚「时空印记」。

作品核心不是复杂功能，而是**氛围与体验**：沉浸的光影、可交互的 NPC、一段「酒保给你一杯酒，也给你一个任务」的小故事，以及四种守护灵试炼（划拳 / 密码 / 寻物 / 符文），让每个疲惫的旅人都能推门走进一座属于自己的休息站。

## 玩法闭环

1. 找中庭吧台后的**酒保「无名」**按 `E` 对话，接下主线任务；
2. 走进四座厅堂，靠近发光印记**自动收取**；
3. 集齐本厅印记后，跟厅中**守护灵**过招（四种小游戏）；
4. 通关拿回**四把时空之钥**；
5. 回到酒保处，触发「时空酒馆 · 重启」结局。

左上角「任务追踪」面板会始终提示你下一步该去哪。

### 操作

| 按键 | 功能 |
|------|------|
| `W A S D` | 行走 |
| 鼠标 | 环顾 |
| `Shift` | 疾行 |
| `F` | 飞行（空格升 / `C` 降） |
| `E` | 与 NPC 交谈 / 拾取 |
| `M` | 静音 |
| `Esc` | 暂停（可调灵敏度 / 音量 / 辉光） |
| `I` | 关于本作品 |

## 技术栈

- 原生 **WebGL + Three.js r160**，全部**本地化**到 `vendor/`，离线也能跑、评审打开即体验；
- 自定义后处理管线：`EffectComposer` + `UnrealBloomPass` 辉光 + `FXAA` + 景深；
- 程序化音效（`Web Audio API`，无外部音频资源）；
- **ES 模块化架构**（非单文件）：`state` 共享状态层 + `world/*` 场景组件 + `core` 引擎，便于开发与查错；
- 轻量可达性自检脚本 `tools/reach-check.cjs`（验证所有 NPC / 物品可交互）。

## 本地运行

ES 模块不支持 `file://` 协议，必须用任意静态服务器访问：

```bash
cd 本仓库目录
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123
```

## 工程结构

```
.
├── index.html            # 入口：外链样式 + importmap + 模块加载
├── styles.css            # 全部 UI 样式（金/暗科幻酒馆风）
├── vendor/               # 本地化的 three.module.js 与后处理插件
├── src/
│   ├── state.js          # 共享状态 / 渲染器 / 灯光 / 工具函数
│   ├── audio.js          # 程序化音效
│   ├── quest.js          # 主线任务 / 四种试炼 / 胜利结局
│   ├── core.js           # 引擎：控制 / 对话 / HUD / 小地图 / 碰撞 / 主循环
│   └── world/
│       ├── environment.js  # 外部夜景与酒馆外观
│       ├── interior.js     # 时空枢纽内部
│       ├── halls.js        # 四座主题厅 + 传送门
│       ├── npc.js          # 酒保与四位守护灵
│       └── tokens.js       # 四枚时空印记
└── tools/
    └── reach-check.cjs   # 几何可达性自检
```
